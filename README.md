# TaskTracker - Bootcamp II (Fase 2)

## Descrição Funcional
O TaskTracker é uma aplicação de linha de comandos (CLI) que atua como um organizador digital. O sistema permite ao utilizador cadastrar novas tarefas com validação de regras de negócio, definir os níveis de prioridade e visualizar a lista de tarefas pendentes de forma estruturada.

## Tecnologias Utilizadas
* Python 3
* Git
* GitHub
